# 🏏 IPL 2022 Capstone Project – Data Visualization

## 📌 Project Overview

The **IPL 2022 Capstone Project** is a Data Visualization and Exploratory Data Analysis project based on Indian Premier League (IPL) 2022 match data.

The purpose of this project is to explore IPL 2022 match statistics, identify meaningful patterns, and generate insights using different data visualization techniques.

The project focuses on match results, team performance, toss decisions, batting performance, bowling performance, venues, and Player of the Match statistics.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze IPL 2022 match data.
* Understand team-wise performance.
* Analyze the impact of toss results and toss decisions.
* Compare first and second innings scores.
* Identify top-performing batsmen.
* Analyze bowling performances.
* Identify Players of the Match.
* Analyze match-winning margins.
* Explore venue-wise match statistics.
* Create meaningful visualizations from the dataset.
* Extract useful insights from the data.

## 📊 Dataset

The dataset contains IPL 2022 match-level information.

### Important Columns

| Column Name           | Variable Type | Description                            |
| --------------------- | ------------- | -------------------------------------- |
| `date`                | String        | Date on which the match was played     |
| `venue`               | String        | Venue where the match was played       |
| `stage`               | String        | Stage of the tournament                |
| `team1`               | String        | First team participating in the match  |
| `team2`               | String        | Second team participating in the match |
| `toss_winner`         | String        | Team that won the toss                 |
| `toss_decision`       | String        | Decision taken after winning the toss  |
| `first_ings_score`    | Integer       | Score in the first innings             |
| `second_ings_score`   | Integer       | Score in the second innings            |
| `match_winner`        | String        | Team that won the match                |
| `won_by`              | String        | Match won by Runs or Wickets           |
| `margin`              | Integer       | Winning margin                         |
| `player_of_the_match` | String        | Player awarded Player of the Match     |
| `top_scorer`          | String        | Top run scorer in the match            |
| `highscore`           | Integer       | Highest score by the top scorer        |
| `best_bowling`        | String        | Best-performing bowler                 |
| `best_bowling_figure` | String        | Best bowling figures, e.g. `4/20`      |
